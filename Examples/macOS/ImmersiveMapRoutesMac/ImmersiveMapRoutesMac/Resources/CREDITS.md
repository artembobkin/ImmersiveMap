## biplane.obj, biplane.mtl, diffuse_512.png

Low-Poly Biplane by mfep.

- License: CC0 1.0 Universal (public domain dedication). Attribution is not
  required; the author asks for a link to their OpenGameArt profile if you feel

Modified for this example: rotated -90 degrees about Y so the model matches the
ImmersiveMap scene model convention (-Z forward at heading 0, +Y up), and
`biplane.mtl` was added so the bundled diffuse texture binds through Model I/O.
